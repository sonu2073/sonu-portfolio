# Sonu Meena — Data Analyst Portfolio

A personal portfolio site built to showcase my data analytics projects, experience, and skills — styled as a live analytics dashboard, since that's the world I work in.

**Live site:** [sonumeen.tech](https://sonumeen.tech) *(also available at [sonu-portfolio-1ue7.vercel.app](https://sonu-portfolio-1ue7.vercel.app))*

---

## About

I'm a final-year MCA student (University of Kota) and aspiring Data Analyst / Business Analyst, with a B.Sc. in Computer Science from the University of Delhi. This site brings together my internship experience, project work, and skills in one place for recruiters and collaborators.

## Features

- **Dashboard-inspired design** — dot-grid background, monospace data labels, and a stat strip pulled from real project numbers (rows analyzed, visualizations built, internships completed)
- **Live status indicator** signaling current availability for Data Analyst / Business Analyst roles
- **Project case studies** with mini charts (sparklines, bar comparisons, ring charts) reflecting each project's actual output
- **Skills section** styled as system status bars across languages, analysis, and BI tools
- Fully responsive, single-file, no build step required

## Tech Stack

- HTML5, CSS3 (custom properties, CSS Grid/Flexbox), vanilla JavaScript
- Fonts: [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk), [Inter](https://fonts.google.com/specimen/Inter), [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) via Google Fonts
- Hosted on [Vercel](https://vercel.com)

```bash
cd <repo-name>

```

## Deployment

This project is deployed on **Vercel**, connected directly to this GitHub repository. Any push to the `main` branch triggers an automatic redeploy.
