## 🚀 How to Run Locally

1. Clone the repository

```bash
git clone https://github.com/sonu2073/portfolio.git
```

2. Open the project folder

```bash
cd portfolio
```

3. Open `index.html` in your browser

or use VS Code Live Server:

```bash
Right Click → Open with Live Server
```
